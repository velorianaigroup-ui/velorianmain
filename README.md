# Velorian Website

Official website for Velorian.

## Project Structure

```
velorian-website/
├── public/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── main.js
│   └── index.html
├── package.json
└── README.md
```

## Getting Started

Serve the `public/` directory with any static file server:

```bash
npm start
```

This uses `npx serve` to host the site locally.
